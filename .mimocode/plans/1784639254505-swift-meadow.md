# Plan: Absolute Overlay Expand Strategy for MovieCard

## Problem
Current approach animates card width in the flex flow, which:
- Causes bounce/jitter on height transitions
- Doesn't work well on all screen sizes
- Pushes siblings in the flex row, affecting scroll position

## New Strategy: Absolute Overlay Expand
The card keeps its **fixed dimensions in the flow** (192x288px). On hover, an expanded overlay appears via `position: absolute`, visually expanding on top of siblings without changing the flow layout.

## Changes

### `src/components/movie-card/index.tsx`

1. **Remove `motion/react` width/height animation** — no more `animate={{ width, height }}`
2. **Card root**: Fixed dimensions `w-48 aspect-[2/3]` always, no width change
3. **Normal state**: Poster image fills the card (same as now)
4. **Hover state**: An absolutely-positioned expanded overlay appears:
   - `position: absolute` with calculated `top`/`left` to center on the card
   - Width: 320px (`w-80`), height: auto (content-driven)
   - High `z-index` (50) to appear above siblings
   - Smooth fade-in + scale transition via `motion/react`
   - `pointer-events: auto` on hover, `pointer-events: none` when hidden
5. **Overflow**: The expanded overlay will extend beyond the parent's visible bounds — this is intentional. The parent's `overflow-hidden` on TrendingSection wrapper clips the edges, which is fine since the expanded content is readable within the viewport.

### Layout Detail
```
Normal card (fixed in flow):
┌──────────┐
│  poster  │  192x288px, shrink-0
│          │
└──────────┘

Hovered card (overlay expands beyond):
        ┌────────────────────┐
        │   backdrop image   │  absolute, z-50
        │                    │  320px wide
        │  action buttons    │  extends above/below
        │  metadata          │  the original card bounds
        │  title, overview   │
        │  genres            │
        └────────────────────┘
   ┌──────────┐
   │ (poster) │  original card stays in flow, unchanged
   └──────────┘
```

### `src/pages/home/partials/trending-section.tsx`

No changes needed. The wrapper already has `overflow-hidden py-16 -my-16` which:
- Clips the horizontal edges (left/right overflow from expanded cards)
- The `py-16 -my-16` already allows vertical overflow to bleed
