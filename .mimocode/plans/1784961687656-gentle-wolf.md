## PHASE 1: Logic Bugs (Critical/High)

### 1.1 `selectedQuality` tidak di-reset saat provider berubah
**File:** `src/pages/netflix-player/partials/hls-player.tsx` (auto-failover effect, ~line 199) + manual provider switch
**Bug:** Saat pindah provider, `selectedQuality` tetap di index lama. Jika provider baru punya fewer sources → `sources[selectedQuality]` = `undefined` → player hitam, tanpa error/spinner.
**Fix:**
- Tambahkan `setSelectedQuality(0)` di auto-failover step 3 (`onProviderChange(providerIndex + 1)`)
- Tambahkan `setSelectedQuality(0)` di manual provider switch (`top-app-bar.tsx` dan "Try another provider" button)
- Tambahkan `setSelectedQuality(0)` saat `onRefetchCurrentProvider` dipanggil (step 2)

### 1.2 `handleRetry` tidak re-init HLS instance
**File:** `src/pages/netflix-player/partials/hls-player.tsx` (~line 414-422)
**Bug:** Setelah fatal error, HLS instance sudah `destroy()`. Retry hanya clear error + `video.play()` → stream mati, user lihat layar hitam.
**Fix:** Retry harus trigger re-load. Cara: set `selectedQuality` ke value yang sama paksa re-render, atau tambah state `retryKey` yang increment setiap retry → dipakai sebagai dependency di `useHlsLoader`.

### 1.3 `useWatchProgressTracker("movie", ...)` hardcoded
**File:** `src/pages/netflix-player/partials/hls-player.tsx` (line 307)
**Bug:** TV show progress disimpan sebagai "movie", resume progress tidak pernah benar untuk TV.
**Fix:** Ganti ke `useWatchProgressTracker(mediaType, movieId, true)`

### 1.4 "Back to movie" link hardcode `type: "movie"`
**File:** `src/pages/netflix-player/index.tsx` (line 127)
**Bug:** Saat watch TV show, klik "Back to movie" navigasi ke halaman movie yang salah.
**Fix:** `params={{ type: mediaType, id }}` + ubah label "Back to movie" → "Back to detail" atau "Back to {mediaType}"

## PHASE 2: Re-render Fixes (High/Medium)

### 2.1 Wrap `BottomControls` di `React.memo`
**File:** `src/pages/netflix-player/partials/player-ui/bottom-controls.tsx`
**Bug:** Re-render ~10x/detik karena parent state `currentTime` berubah terus.
**Fix:** `export const BottomControls = React.memo(function BottomControls({...}) {...})`

### 2.2 Wrap `TopAppBar`, `PausedOverlay`, `SubtitleOverlay` di `React.memo`
**File:** Masing-masing partial
**Fix:** Tambah `React.memo` wrapper. `SubtitleOverlay` perlu `prevProps.currentActiveCues === nextProps.currentActiveCues` check (atau fix di use-subtitles.ts).

### 2.3 Wrap handler functions di `hls-player.tsx` dengan `useCallback`
**File:** `src/pages/netflix-player/partials/hls-player.tsx`
**Handlers:** `togglePlay`, `toggleMute`, `handleVolumeChange`, `handleProgressClick`, `handleProgressHover`
**Fix:** Bungkus masing-masing dengan `useCallback` (deps: `[]` karena hanya pakai refs).

### 2.4 Fix `useMemo` di `useSubtitles` untuk return referensi stabil
**File:** `src/pages/netflix-player/hooks/use-subtitles.ts` (~line 223-240)
**Bug:** Memo selalu return array baru meskipun cues sama → SubtitleOverlay re-render sia-sia.
**Fix:** Simpan `prevResult` di ref, bandingkan length + setiap cue object, return referensi lama jika sama.

### 2.5 Wrap callbacks ke `useVideoEvents` dengan `useCallback` + fix deps
**File:** `src/pages/netflix-player/partials/hls-player.tsx` (lines 228-289)
**File:** `src/pages/netflix-player/hooks/use-video-events.ts` (line 65)
**Fix:** Bungkus semua callback dengan `useCallback`, tambahkan ke deps array `useVideoEvents`, hapus `eslint-disable`.

### 2.6 Cleanup timer di unmount
**File:** `src/pages/netflix-player/partials/hls-player.tsx` (~line 310-316)
**Bug:** `hideTimerRef` dan `mobileSkipTimerRef` tidak di-clear saat unmount.
